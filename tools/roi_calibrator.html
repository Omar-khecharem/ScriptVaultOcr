Calibrage des zones d'examen → SCRIPTVAULT_ROI

1. Sélectionnez un champ dans la liste, puis cliquez-glissez sur le scan pour tracer le rectangle de la zone d'écriture (allez au centre du ceilulier, pas sur les étiquettes imprimées). 2. Molette = zoom sur le pointeur ; bouton du milieu (molette) enfoncé ou Espace maintenu + clic-droit = pan. 3. Répétez pour chaque champ. 4. Cliquez Copier le JSON et placez le résultat dans la variable d'environnement SCCRIPTVAULT_ROI (JSON, fractions normalisées [x0, y0, x1, y1] de la page).
